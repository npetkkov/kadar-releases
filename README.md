# Kadar — версии

Тук са само готовите версии на **Kadar** — instant replay за Windows (запазва последните минути от играта с една клавишна комбинация, включително звука от Discord и микрофона).

**Първо инсталиране:** от [Releases](../../releases/latest) свали `Kadar.zip`, разархивирай го където искаш и пусни `Kadar.exe`.

**Обновяване:** Kadar проверява тук сам, сваля новата версия тихо и я инсталира при следващото пускане. Нищо не трябва да правиш.

`Kadar-update.zip` е само за автоматичното обновяване — не го сваляй ръчно.
